# Agenx brand

Nguồn thiết kế nhận diện của Agenx: icon ứng dụng, logo.

```
Brand/
└── Icon/
    ├── agenx-icon-dark.svg        bản gốc 1024 × 1024 — nền tối
    ├── agenx-icon-light.svg       bản gốc 1024 × 1024 — nền sáng
    └── png/
        ├── dark/agenx-dark-{16,32,64,128,256,512,1024}.png
        └── light/agenx-light-{16,32,64,128,256,512,1024}.png
```

| Thư mục | Nội dung |
|---|---|
| `Icon/` | Icon ứng dụng — SVG là nguồn, PNG xuất từ SVG theo 7 kích thước |
| `Logo/` | {{Logo chữ / logo đầy đủ — chưa có}} |

**SVG là nguồn, PNG là bản xuất.** Muốn sửa icon thì sửa SVG rồi xuất lại cả bộ PNG, đừng sửa riêng một kích thước — sửa lẻ thì các cỡ sẽ lệch nhau.
